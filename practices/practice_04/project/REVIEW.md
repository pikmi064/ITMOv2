## Подлинность доказательства hook

В `output/opencode-hook-demo.json` указаны модель `vsellm/anthropic/claude-sonnet-5.5` и `exit_code: 0`. Последовательность событий: чтение README → успешный `edit` → текст модели с «Статус AUTO CHECK: PASS» и «Тесты логики: 7 из 7 прошли». В ответе edit есть полный вывод runner и итог `OK`.

`callID` правки — `toolu_bdrk_0196zkm9NsExAHQAdE3Nra44`. В `output/hooks.jsonl` найден тот же идентификатор, `tool: edit`, `status: PASS`, время `2026-10-07T20:15:49.269Z` и вывод runner. В событиях сессии нет отдельного запуска проверок через shell. Код plugin добавляет этот результат именно в ответ инструмента; сценарий запрещает shell. Это подтверждает автоматическое срабатывание и получение результата моделью.

`output/opencode-demo.json` имеет `exit_code: 124`: это частичный запуск Qwen. Его завершённые вызовы правил, skills и собственного MCP подтверждены, но вся сессия не считается успешной. Первый Sonnet-запуск и старый hook-запуск также не засчитаны как полностью успешные. Документы различают эти случаи корректно.
