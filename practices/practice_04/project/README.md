# Учебный трекер

Небольшой локальный проект для практики 4: список учебных задач со сроками и предметами.

## Запуск

```bash
cd practices/practice_04/project
python3 server.py
```

Откройте <http://127.0.0.1:8040>. Остановка — Ctrl+C. Другой порт: `python3 server.py --port 8041`.

Python 3.10 или новее. Сам веб-трекер работает без внешних зависимостей; собственному MCP нужен пакет `mcp`. Данные хранятся в `data/tasks.sqlite3` и сохраняются между перезапусками.

## Среда агента

```bash
make setup
make check
opencode
```

Команды выполняются из этой папки. Установленный OpenCode — 1.18.31; hook использует его API `tool.execute.after`. Для браузерного skill и runner нужен Node.js с `npx`.

В `opencode.json` выбрана уже настроенная пользователем облачная модель `vsellm/anthropic/claude-sonnet-5.5`, подключены собственный MCP `study_tracker` и удалённый Context7. Учётные данные VseLLM берутся из пользовательского конфига OpenCode и не хранятся в проекте. На другом компьютере нужно подключить доступного провайдера и выбрать модель через `/models`. Ollama для практики 4 не нужен. Файлы настроек практики 3 не используются.

`AGENTS.md` задаёт правила. Проектные skills лежат в `.agents/skills/`, hook — в `.opencode/plugins/check.js`. Context7 подключён с анонимным доступом; его лимиты могут ограничивать частые запросы. Ключи в проект не добавлены.

Подробный сценарий демонстрации и ссылки на подтверждения: [DEMO.md](DEMO.md). Разбор skills: [SKILLS_REVIEW.md](SKILLS_REVIEW.md).

## Возможности

- Добавление задачи с предметом и необязательным сроком.
- Отметка выполнения и возврат задачи в работу.
- Фильтры: все, в работе, просроченные, готовые.
- Поиск по названию и предмету.
- Удаление с подтверждением.

## Устройство

`server.py` — HTTP API и SQLite. `index.html` — интерфейс без сборки и библиотек. Сервер слушает только `127.0.0.1`; приложение рассчитано на одного пользователя.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/tasks` | Все задачи |
| POST | `/api/tasks` | Создать: `title`, `subject`, `deadline` |
| PATCH | `/api/tasks/{id}` | Изменить статус: `done` (boolean) |
| DELETE | `/api/tasks/{id}` | Удалить |

Срок имеет формат `YYYY-MM-DD` или пустую строку. Ошибки ввода возвращают HTTP 400 и JSON с полем `error`; отсутствующая задача — HTTP 404.

## Применение для практики

Правила агента, skills Playwright и Context7, собственный MCP get_deadlines и hook автоматической проверки подключены. Проверка запускается после правок через инструменты OpenCode и возвращает результат агенту. После изменения файла агент получает результат автоматической проверки.
