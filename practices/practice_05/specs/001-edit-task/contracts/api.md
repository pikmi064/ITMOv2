# Общий контракт UI ↔ логика v1.0

Дата: 2026-10-28. Решения принимает основной агент по прямому поручению пользователя. Это не утверждение о ручной приёмке человеком. Контракт фиксируется до кода.

## Данные и запрос
`PUT /api/tasks/{id}` — ровно три обязательных строковых ключа: title, subject, deadline. title.strip(): 1–160 символов Python, subject.strip(): 0–80. UI не обрезает данные. Предмет/срок очищаются пустой строкой. Дата: пусто или действительная YYYY-MM-DD; прошлые даты допустимы. Неизвестные ключи, включая done/id, → 400.

200: полный объект {id: integer, title: string, subject: string, deadline: string, done: 0|1}. Сохранить id/done. Обновить одну запись параметризованным SQL, UPDATE и SELECT одной транзакцией. Повтор PUT идемпотентен по значениям. Между клиентами последнее сохранение побеждает, версий нет.

## Ошибки
Сначала маршрут/id: ASCII-цифры, 1..9223372036854775807, ведущие нули допустимы, иначе 404. Затем тело: UTF-8 JSON-объект, 1..8192 байт, корректный Content-Length и все поля, иначе 400. Затем наличие записи: отсутствует → 404 без создания. Любая ошибка: JSON {error: string}. Валидация до UPDATE, никаких частичных записей.

## UI
Кнопка «Изменить» у видимой задачи, доступное имя содержит название. Один native dialog, подписанные поля, фокус в title. Сохранить/Enter отправляют один PUT; поля, повторная отправка, закрытие и Escape блокированы во время запроса. Отмена/Escape до отправки — без записи. Ошибка сохраняет draft, role=alert, возможность исправить/повторить/отменить. При обрыве сети результат может быть неизвестен; повтор безопасен по значениям.

200 PUT подтверждает сохранение: UI заменяет локальную задачу ответом, закрывает диалог и делает GET для серверной сортировки. Ошибка этого GET: «Задача сохранена, но список не обновлён», подтверждённые локальные данные остаются. Фильтр/поиск сохраняются; задача может исчезнуть из выборки. Фокус после закрытия — новой кнопке той же задачи, иначе поиску. Текст только через textContent/value. Окно 375px без горизонтальной прокрутки.

## Совместимость и границы
POST создания, PATCH done, DELETE, GET, поиск, фильтры, статистика и серверная сортировка сохраняются. Миграции нет. project/ — отдельный snapshot server/index/deadlines и тестов практики 4; старый MCP и окружение остаются в практике 4. Пользовательскую БД не копируем. Не входят: undo, история, аккаунты, синхронизация, массовые правки, обнаружение конфликтов.

AC4: создание, done/undone, удаление, поиск/фильтр/сортировка работают после правки.
AC5: клавиатура, доступные имена/фокус, безопасный вывод, 375px.
