# Согласование команды логики до кода

Дата: 2026-10-28. Исполнитель: отдельный агент команды логики. Это реальная сверка документов агентом, а не заявление об участии человека или о выполненных тестах.

Прочитаны независимые `specs/before/logic.md`, `specs/before/ui.md` и общий `specs/001-edit-task/contracts/api.md` v1.0. Проверены данные, HTTP метод, ответы, ошибки, очистка, сохранение done, обновление списка и состояние draft. Итог записан только в `specs/001-edit-task/logic.md`; исходные варианты сохранены.

| Область | Итог сверки и принятое решение |
|---|---|
| PUT или PATCH | Обе команды предложили PUT. Принят `PUT /api/tasks/{id}`, старый PATCH done остаётся отдельным. |
| Полнота данных | Ровно title/subject/deadline, все обязательны. Пустые optional очищаются; лишние ключи отклоняются. UI согласован с этой формой запроса. |
| Нормализация | title/subject нормализует сервер; лимиты считаются после strip в символах Python. Дата — каноническая строка или пусто. UI не должен молча обрезать значения. |
| Успешное сохранение | 200 содержит полный объект с прежними id/done. UI использует этот объект до отдельного GET; это снимает неопределённость при ошибке обновления списка. |
| PUT success + GET fail | Сообщение явно подтверждает сохранение и отдельно сообщает неудачу обновления списка. Нельзя сообщать «не сохранено». |
| 400/404/сеть | Ошибка JSON; draft остаётся. 404 не создаёт копию. Повтор после сетевой ошибки допустим. |
| Конкурентность | Последнее успешное сохранение побеждает. Повтор PUT идемпотентен по значениям, но не защищает от перезаписи чужой конкурентной правки. Версий/409 нет. |
| ID и порядок ошибок | Взяты точные правила контракта: положительный signed int64, ASCII, ведущие нули допустимы; маршрут/id перед телом, наличие записи после тела. |
| Совместимость | No migration, сохранение done и старых POST/PATCH/DELETE/GET; порядок перечитывается с сервера, поиск/фильтр остаются. |

Блокирующих противоречий с контрактом v1.0 не обнаружено. Реализация на момент этой сверки не создавалась этим агентом. Приёмку AC1–AC5 ещё необходимо подтвердить фактическими проверками после реализации.
